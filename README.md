# 아마추어 글쓰기 — 밤의 문장들 v14.29

## 새로 추가된 기능

### 🍽️ 다과방의 세 가지 요리
기존 **따뜻한 차 / 과자 / 젤리**를 유지하면서, 다과방 뒤쪽 서빙 카운터에 다음 3가지 요리의 경량 3D 모델을 추가했습니다.

- **🥩 토마호크 스테이크**: 뼈가 붙은 두툼한 구운 스테이크와 그릴 자국, 허브
- **🥓 삼겹살 구이**: 구운 고기·지방층·그릴 자국·채소
- **🍝 까르보나라 스파게티**: 소스가 있는 파스타 면과 베이컨, 후추

다과방 카운터에 가까이 가서 `E`/모바일 상호작용 버튼을 눌러 **6개 메뉴 중 하나를 선택**할 수 있습니다. 음식 선택은 기존 간식과 동일하게 즉시 머리 위 음식 아이콘과 짧은 효과로 표시되며, **같은 모임방의 다른 참가자에게도 전달**됩니다. 3D 음식은 정지된 서빙 오브젝트로, 실제 먹는 애니메이션이나 인벤토리 기능은 포함하지 않습니다.

### 😊 책과 방명록 댓글 이모티콘

- **공개 책 본문 아래 댓글** 및 **방명록의 각 글 아래 댓글** 모두 `😊 이모티콘` 버튼을 누르면 20개의 이모티콘 선택창이 나타납니다.
- 선택한 이모티콘은 댓글 입력창의 **커서 위치에 삽입**됩니다. 본문과 함께 저장되므로 다른 참가자도 그대로 읽을 수 있습니다.
- 댓글 한 개당 기존 **최대 400자** 제한을 유지합니다. 이모티콘을 넣어서 한도를 넘기는 경우에는 이유를 안내하고 글을 훼손하지 않습니다.
- 방명록 본문은 기존 500자 제한, 책은 기존 10,000자 제한을 유지합니다.

## 기존 기능 및 데이터 보존

- v14.28의 **별이 가득한 남색 우주 배경과 창밖 별**, 글쓴이별 책장, 본문 연속 스크롤, 책 공개·수정·삭제, 방명록과 댓글, 반려동물 산이·보리·햇살이, 실시간 채팅을 유지합니다.
- 기존 Supabase `writing_room_shelves` 테이블과 환경 변수(`SUPABASE_URL`, `SUPABASE_SECRET_KEY`)는 **변경하지 않습니다**. SQL을 새로 실행할 필요도 없습니다.
- 이 프로젝트는 **서버 파일**도 함께 갱신해야 신규 음식 반응이 모든 참가자에게 보입니다.
- Render 무료 서버의 영구 보존은 **Supabase가 정상 연결된 경우에만** 보장됩니다. `/health`의 `shelfStorage`가 `supabase`인지 확인하세요.

## GitHub → Render 배포

1. **GitHub 업로드용 ZIP**을 압축 해제합니다. 압축을 풀면 `server.js`, `pets-server.js`, `public/`, `package.json`, `supabase_setup.sql`이 **바로** 보여야 합니다.
2. 이 파일들을 기존 GitHub 저장소의 **최상위 경로**에 업로드하여 덮어쓰고 **Commit changes**합니다.
3. Render 자동 배포가 완료된 뒤 사이트의 `/health`에서 `"version":"14.29.0"`을 확인합니다.
4. 기존 방에 입장해 다과방에서 세 가지 음식 선택과 책/방명록 댓글의 이모티콘을 확인합니다. 화면이 바뀌지 않으면 새로고침합니다. CSS/JS URL에는 `v=14.29.0` 캐시 갱신 파라미터가 있습니다.

## 테스트 범위

- Node.js로 서버 및 브라우저 JS 문법 검사 통과
- 테스트 HTTP 서버 `/health` 버전 확인
- PC 브라우저(로컬 HTML 주입)에서 6개 음식 선택, 댓글 이모티콘 삽입 및 JS 예외 없음 확인
- 모바일 390×844 화면에서 6개 음식 메뉴 표시 및 화면 안에 들어오는 것 확인
- 로컬 실제 WebSocket 서버에 두 명 접속: 스테이크/삼겹살/파스타 반응 전달, 이모티콘 포함 방명록 댓글 공유 확인
- 실제 Render 계정과 Supabase 서비스의 배포 결과는 별도 확인하지 않았습니다.
