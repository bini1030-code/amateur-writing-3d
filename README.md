# 아마추어 글쓰기 · v14.8 / 8인 마음 모임과 우리 책장

**기준:** v14.7의 채팅 보존, 서가/다과 아이콘 효과, 음악, 책 공유, 반응, 조명 기능을 유지합니다.

## 바뀐 심리 모임방
- 중앙 활동 테이블 제거; 서로 마주 보는 원형의 철제 의자 **8개** 배치
- 해먹과 빈백 대신 오른쪽 벽에 **카우치** 1개 배치
- 심리 모임방 오른쪽 벽에 **책장** 추가 (모임방 왼쪽의 책장과 동일한 저장 내용)
- 마음 알아보기 / 몰라보기는 **심리방 뒤쪽의 여섯 감정 그림 앞**에서 실행
- 가구 충돌 및 자리에 앉았다 일어날 때 탈출 위치 보정
- 다른 참가자가 이미 앉은 원형 의자는 앉기 후보에서 제외

## 우리가 쓴 글을 책장에 꽂기
1. `나의 글 → 03 글쓰기`에서 제목과 본문을 작성합니다. **작성 중인 초안은 자동으로 공개되지 않습니다.**
2. `📚 내 글 책장에 꽂기`를 누른 뒤, 모든 참가자에게 공유된다는 확인창에서 승인합니다.
3. 같은 모임방 코드로 접속한 멤버는 **두 책장 어디에서나** 작품을 제목·작성자별로 선택해 페이지를 넘기며 읽을 수 있습니다.
4. 책장에는 **최대 64권**, 한 권의 본문은 **최대 10,000자**를 저장할 수 있습니다.

책장은 **모임방 코드별**로 분리됩니다. 초안·개인 감정 기록은 여전히 본인 기기에 보관됩니다. 책장에 꽂은 작품은 **해당 방 코드로 들어온 누구나 읽을 수 있으므로**, 공개를 원하는 글만 꽂아 주세요.

## 책 보존 범위 (중요)
책장에 꽂은 글은 기본적으로 서버의 `data/room-books.json`에 저장되고, 들어온 기기의 브라우저에도 백업합니다.

- 내 PC에서 직접 Node 서버를 운영하는 동안에는 그 파일을 보관하면 서버 재시작 후에도 작품이 남습니다.
- Render Free의 기본 파일 시스템은 **영구 저장소가 아닙니다**. 재배포·재시작 시 서버의 책 파일이 사라질 수 있습니다. 기존 기기에는 로컬 저장소의 복사본이 남아 책장에서 '다시 공유하기'를 선택할 수 있지만, 다른 새 기기에서는 서버에 다시 공유할 때까지 볼 수 없습니다.
- Render의 영구 디스크가 있다면 환경변수 `BOOKSHELF_DATA_DIR`에 마운트 디렉터리 경로를 지정하세요. 영구 저장이 필요한 실운영에서는 DB 또는 영구 디스크 연결을 권장합니다. **이 ZIP만으로 Render 무료 서버에 영구 보존을 보장하지는 않습니다.**
- 서버에 보관된 파일 및 기기의 로컬 저장소를 지우면 복구할 수 없으니 중요한 글은 `나의 글 저장`으로 별도 보관하세요.

## 설치 및 GitHub 업로드
GitHub 업로드용 ZIP을 풀고 **ZIP 자체가 아니라 파일과 `public` 폴더를 저장소 최상위에** 올린 뒤 Commit 하세요. Render 자동 배포가 활성화된 경우 기존 주소에 새 버전이 반영됩니다.
