# 아마추어 글쓰기 — 밤의 문장들 (v14.22)

## 이번 수정: 책 표지 3:2 구획

- 책 표지 위쪽 **60%**: 제목을 크게 중앙 정렬합니다.
- 책 표지 아래쪽 **40%**: 가는 구분선을 두고 `글쓴이 . 이름`을 표시합니다.
- 기존 3열 × 3행으로 **첫 화면에 최소 9권**을 표시하는 책장 배치를 유지합니다(일반적인 PC 및 스마트폰 크기 기준).
- 기존 책장 공개·저장(본문 최대 10,000자), 읽기, 수정·삭제, 비공개 초안, 멀티플레이, 채팅, 심리방 기능은 그대로 유지합니다.
- `미리보기_새표지_1280x850.png`와 `미리보기_새표지_390x844.png`는 실제 브라우저에서 **테스트용 가상 책**을 넣어 촬영한 화면입니다. 사용자 책 데이터를 포함하지 않습니다.

## GitHub에 업데이트하기

1. **GitHub 업로드용 ZIP을 압축 해제**합니다.
2. ZIP 안에 있는 `server.js`, `package.json`, `render.yaml`, `public` 폴더, README 등을 **GitHub 저장소 최상위**에 업로드해 기존 파일을 덮어씁니다. ZIP 자체를 업로드하지 마세요.
3. `Commit changes`를 누른 후 Render 배포를 확인합니다.
4. 배포된 주소 뒤에 `/health`를 붙여 `"version":"14.22.0"`을 확인합니다.
5. 이전 화면이 보이면 브라우저에서 강력 새로고침(Ctrl+Shift+R)을 해 보세요.

## 직접 실행하기

Node.js 18 이상에서 `node server.js` (기본 주소: http://localhost:3000).

## 저장 유의사항

- 책 한 권 본문 제한은 **10,000자**입니다. 공개된 책은 같은 모임방 코드로 접속한 사용자에게 표시됩니다.
- 비공개 초안은 작성한 브라우저에만 보관됩니다.
- Render의 임시 파일 시스템에서는 배포나 재시작 시 서버 책장 데이터가 사라질 수 있습니다. 지속적인 보관에는 `BOOKSHELF_DATA_DIR`가 가리키는 영구 디스크 등이 필요합니다.
