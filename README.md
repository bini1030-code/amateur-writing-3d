# 아마추어 글쓰기 v14.7 — 빛과 함께 나타나는 상호작용 아이콘

기준 버전: v14.6 (책장 읽기, 채팅 기록 보존, 다과룸, 심리방, 조명, 배경음악 등 유지)

- 식물 물주기: 물뿌리개 SVG 아이콘 + 녹색 광원 펄스 동시 시작 및 동시 종료
- 차 마시기: 🍵 + 녹색 빛 / 과자 먹기: 🍪 + 따뜻한 노란빛 / 젤리 먹기: 🍬 + 분홍빛
- 아이콘은 떠오르거나 물방울처럼 퍼지는 파티클이 아니라 제자리에 잠깐 나타났다가 빛과 함께 사라짐
- 아이콘과 광원은 하나의 컨테이너를 이용하고 동일한 820ms 수명(각 800ms 애니메이션, 종료 820ms)
- 같은 모임방에서 다른 사람의 차·과자·젤리 반응 및 물주기에도 아이콘 표시
