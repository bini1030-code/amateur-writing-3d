# 아마추어 글쓰기 — v14.4 · 음악 / 상호작용 안내 개선

기존 v14.3(채팅 기록 보존)를 기반으로 만든 수정 버전입니다.

- 입장 버튼 클릭 후 오리지널 Web Audio 배경음악이 은은하게 반복됩니다. 음악 저작권 파일이나 외부 스트리밍은 사용하지 않습니다.
- 실제 움직일 때 낮고 부드러운 발걸음 소리가 들립니다.
- 소리 켬/끔은 배경음악과 효과음 모두에 적용됩니다. 모바일 브라우저 자동 재생 제한으로 처음 입장 클릭이 필요합니다.
- 심리방 해먹 자세는 하늘을 보고 두 팔을 머리 뒤에 두는 형태입니다.
- 둥근 마음 테이블의 전체 주변에서 감정 활동을 열 수 있습니다.
- 의자, 다과대, 빈백, 해먹, 마음 테이블 근처에서는 상호작용 전 행동 안내가 표시됩니다.
- 상호작용 안내와 실제 실행은 동일한 근처 판정 함수를 사용합니다.
- 기존 채팅 기록 보존, 펼친 책 공유, 스마트폰 조작, 다과 및 감정 기록 기능 유지.
