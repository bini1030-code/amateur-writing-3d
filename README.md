# 아마추어 글쓰기 — 3D 멀티플레이 v5 (부드러운 캐릭터)

이번 수정판은 기존 v4의 모바일·PC 화면, 다중 접속, 글쓰기/낭독, 다과룸/화장실 이동을 유지하면서 **아바타 외형을 새로 모델링**했습니다.

- 얼굴을 단순한 둥근 형태로 변경; 작은 눈, 아주 옅은 미소
- 뺨 옆 머리카락, 돌출된 귀·코, 관절처럼 보이는 팔·다리 제거
- 남자: 짧은 단정한 머리 / 여자: 얼굴 뒤쪽의 단정한 단발머리
- 작은 파스텔 톤의 인형 같은 모습, 부드러운 소매와 신발
- 입장 화면의 남녀 선택 아이콘도 캐릭터 스타일에 맞게 변경

원본 고요뜰교회 사이트의 캐릭터·모델 파일을 복제한 것은 아닙니다. 비슷한 차분하고 귀여운 인상을 목표로 독자적으로 제작했습니다.

기존 Render 서비스 업데이트: 기존 GitHub 저장소의 프로젝트 파일을 이 폴더 내용으로 교체하고 Commit합니다. Render에서 배포가 완료되면 기존 주소 그대로 접속합니다. 새 Render 서비스를 만들 필요는 없습니다.

# 아마추어 글쓰기 — 밤의 문장들 (v4 · 스마트폰/PC 공용)

기존 Render 서비스에 이 폴더 **안의 파일을 모두** 덮어써서 GitHub에 커밋하면 **같은 웹주소**에서 스마트폰/PC로 접속할 수 있습니다.

## 이번 버전
- 모임방 상하·양쪽 의자가 **테이블 중심을 보도록** 회전하며 캐릭터 착석 방향과 일치합니다.
- 얼굴 옆 뺨 아래 이상한 머리카락 제거. 남자(짧은 머리), 여자(단정한 뒷머리/어깨 길이) 캐릭터 모델을 별도 제작했습니다.
- 닉네임 입력 후 남자/여자 아바타 및 옷 색상을 선택하며, 다른 참가자의 화면에도 선택 모델이 보입니다.
- 스마트폰: 전체 화면 3D, **왼쪽 조이스틱 이동**, **3D 화면 드래그 시점 회전**, 앉기/이용 버튼, 다과룸/화장실 터치 이동, 하단 글쓰기/함께/대화 메뉴에서 패널 열기 및 닫기.
- 기존 멀티플레이(WebSocket), 채팅, 낭독 및 대신 읽기, 반응과 효과음, 다과룸/화장실 경로 찾기를 유지합니다.

## 지금 웹주소에서 사용하기
1. ZIP을 풀고 GitHub 기존 저장소로 이동합니다.
2. 저장소의 `server.js`, `package.json`, `render.yaml`, `public/index.html`, `public/engine.js`, `public/game.js`, `public/style.css` 를 새 버전 파일로 교체합니다. 폴더 구조를 유지해야 합니다.
3. GitHub에서 Commit changes. Render Auto Deploy가 활성화돼 있다면 배포가 시작됩니다.
4. Render에 `Live`가 나타나면 기존 `https://...onrender.com` 웹주소를 스마트폰으로 열어 봅니다. 캐시가 남으면 브라우저 새로고침을 해주세요.

## 로컬 실행
Node.js 18 이상 환경에서 `node server.js` 실행 후 `http://localhost:3000`으로 접속합니다. 파일 HTML만 단독으로 열면 멀티플레이가 동작하지 않습니다.

## 주의
- Render 무료 서버는 비활성 상태에서 일시 중단되거나 첫 접속이 느릴 수 있습니다.
- 실시간 마이크는 HTTPS가 필요하고 일부 통신망에서는 TURN 설정이 없으면 연결되지 않을 수 있습니다.
- 이 ZIP 자체는 공개 URL이 아닙니다. 기존 Render 서비스에 배포해야 링크로 동작합니다.
- 스마트폰 성능에 따라 프레임레이트가 달라집니다. 진짜 스마트폰 기기별 검증 및 공개 서비스 규모 운영에는 추가 테스트가 권장됩니다.
