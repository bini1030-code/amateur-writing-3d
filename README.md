# 아마추어 글쓰기 — 밤의 문장들 v13

## v13 캐릭터 개선
- 남녀 캐릭터를 실제 사람에 가까운 미니멀한 비율로 재설계했습니다. 머리 크기와 얼굴의 둥근 느낌을 줄였습니다.
- 기존에 여러 개의 타원체를 붙이던 머리카락 대신, 두상에 밀착되는 연속된 메시를 사용합니다. 남자는 짧은 머리, 여자는 단정한 단발입니다.
- 캐릭터 몸통을 완만한 곡면으로 연결하고, 곡면의 색을 정점마다 부드럽게 이어 폴리곤 경계를 완화했습니다.
- 남녀 캐릭터와 여섯 가지 옷 색상 선택, 걷기/앉기, 기존 실내 조명, 글 공유, 다과룸, 심리 모임방을 유지합니다.
- 테이블, 의자, 화분 등의 장애물 충돌 판정도 v12에서 이어받았습니다.

## 배포
GitHub 저장소의 루트에 `public/`, `server.js`, `package.json`, `render.yaml` 등을 놓습니다.
Render에서 Node Web Service를 사용하고 `node server.js`로 실행합니다.

**참고:** 캐릭터는 실제 웹용 절차적 3D 메시이며, 앞서 제작한 고품질 캐릭터 시안의 정교한 질감/헤어 스트랜드를 그대로 사용하는 3D 모델은 아닙니다.
