# 아마추어 글쓰기 3D — v14.12 책장 저장 개선

기존 v14.11의 여섯 얼굴 이야기, 글쓰기, 8인 원형 모임, 책장 두 곳, 채팅 기록 등 기능을 유지하며 책장 저장을 보완했습니다.

## 변경 사항

- 글쓰기 화면에서 `내 글 책장에 꽂기`를 누르면 책장 창이 열리고 **저장 중 / 성공 / 실패 메시지**를 바로 보여줍니다.
- 저장 실패 문구의 대비 강화: 오류는 붉은 글씨/연분홍 배경, 성공은 짙은 녹색/연녹색 배경, 저장 중은 짙은 갈색/연노랑 배경.
- 서버가 응답하지 않을 경우 같은 요청 ID로 한 번 더 시도해 중복 등록을 막습니다.
- 서버 파일 저장에 실패하면 임시 공유가 가능하며, **영구 저장되지 않았다는 경고**를 보여줍니다. 동일 기기의 책장 데이터는 브라우저에도 사본이 남습니다.
- 서버 버전 불일치 가능성을 안내하고, `GET /health` 응답에 버전 번호를 제공합니다.

## 배포 및 저장 확인

**GitHub 업로드용 ZIP은 압축 해제했을 때 바로 `server.js`, `package.json`, `public/` 폴더가 보입니다.** 이 파일을 기존 GitHub 저장소의 최상위에 덮어써야 합니다. `amateur-writing-3d-...` 같은 추가 폴더 아래 올리면 기존 서버에 반영되지 않습니다.

Render 배포 후 `https://내-서비스-주소/health`에 접속해 `version`이 `14.12.0`인지 확인하세요. 그 뒤 모임방에 접속해 책장에 테스트 글을 꽂고 저장 성공 메시지가 표시되는지 확인하세요.

## 영구 저장 주의

서버는 기본적으로 `data/room-books.json`에 책을 저장합니다. Render **무료 요금제의 임시 디스크는 재시작/재배포 때 초기화**될 수 있습니다. 다른 기기에서도 글을 계속 유지하려면 별도 데이터베이스나 지속성 있는 저장 공간이 필요합니다.
