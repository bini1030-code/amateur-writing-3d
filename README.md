# 아마추어 글쓰기 — 밤의 문장들 v10

스마트폰·PC에서 접속하는 3D 멀티플레이 글쓰기 모임입니다. **v9에서 v10으로 업그레이드**했습니다.

## 새 기능
- 첫 번째 캐릭터 시안을 참고한 절제된 3D 동글 캐릭터: 남녀 선택, 6가지 니트 색상, 풍성한 자연스러운 머리, 미소·볼 터치·니트 무늬
- **실내 기본 밝기 낮춤**. WebGL 조명 셰이더에서 방의 위치에 따라 따뜻한 램프빛·라벤더빛이 3D 물체와 캐릭터에 반영됩니다. 화면형 글로우와 상호작용 광원도 강화했습니다.
- **옛 화장실 자리에 ‘내 마음은 왜 여섯 얼굴일까?’** 심리 모임방을 설치했습니다. 여섯 얼굴(기쁨·슬픔·화·불안·평온·기대) 조명과 중심 일기장, 보랏빛 카펫이 있습니다.
- 심리방에서 `E` 키 또는 모바일 하단 **상호작용**을 누르면 **내 마음 알아보기**(감정 고르기·원인·필요한 말 기록), **내 마음 몰라보기**(이름 모를 기분을 질문으로 글쓰기) 두 활동이 열립니다.
- 감정 활동 내용은 **본인 기기 로컬 저장소에만** 보관합니다. **감정 이름만 나누기**를 직접 누른 경우에는 선택한 감정 이름만 다른 참가자에게 공유되며 기록 본문은 보내지 않습니다. 글쓰기로 옮긴 문장 역시 참가자가 별도로 공유하기 전에는 타인에게 보이지 않습니다.
- 기존 다과룸(차·과자·젤리), 글쓰기, 펼친 책으로 글 공유, 채팅, 음성 기능을 유지합니다.

## 사용
- **모임방**: 의자에 앉고 글을 씁니다.
- **다과룸**: 서서 차·과자·젤리를 고릅니다.
- **여섯 얼굴의 방**: 여섯 감정과 글감으로 마음을 탐색합니다. **심리 진단이나 치료 기능은 아닙니다.**
- PC: WASD 이동 / E 상호작용 / F 앉기 / V 시점 변경. 모바일: 왼쪽 조이스틱, 하단 상호작용, 장소 이동.

## 로컬 실행
Node.js 18 이상에서 프로젝트 최상단 `node server.js` 실행 → `http://localhost:3000` 접속.

## Render + GitHub 배포
압축을 풀어 `server.js`, `package.json`, `render.yaml`, `public` 폴더가 **저장소 최상위**에 있도록 업로드합니다. Render의 Web Service를 해당 저장소에 연결하세요. Build Command: `echo "No dependencies to install"`, Start Command: `node server.js`.

## 참고
- 프라이버시: 직접 공개한 글/채팅/반응 및 명시적으로 공유한 감정 **이름**만 같은 방 참가자에게 전송됩니다. 감정 기록 본문은 전송되지 않습니다.
- 마이크 연결은 브라우저 권한과 네트워크 환경에 따라 달라집니다.
- WebGL이 없는 경우 간단한 소프트웨어 3D 표시로 대체합니다. 추가 광원은 주로 WebGL에서 더 잘 보입니다.
