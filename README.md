# 아마추어 글쓰기 — v14 수정판

실제 WebGL 3D 모델 시안에 맞춰 남녀 캐릭터와 심리방 가구를 개선했습니다.

- 남성: 자연스러운 짧은 머리 / 바지
- 여성: 자연스러운 단발 윤곽 / 치마
- 기본 옷 색상 여섯 가지 선택
- 심리방: 쿠션형 빈백 두 개, 길이 방향으로 처진 천 해먹과 받침 프레임
- `상호작용` 버튼: 빈백·해먹 근처는 앉기/눕기, 중앙 테이블 근처는 내 마음 알아보기/몰라보기
- 가구 옆에서 일어나면 충돌 영역 바깥의 안전한 위치를 검색
- 기존 글쓰기, 책 공유, 다과룸, 멀티플레이 기능 유지

## 실행
`npm start` 또는 `node server.js`
Render Web Service의 Start Command: `node server.js`

## 참고
3D 모델은 별도 외부 모델 파일이 아닌 코드에서 생성하는 메시입니다. 스마트폰 기종별 그래픽 표현은 추가 확인이 필요합니다.
