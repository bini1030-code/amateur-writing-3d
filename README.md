# 아마추어 글쓰기 — 밤의 문장들 v7

3D 멀티플레이 글쓰기 모임 (PC/스마트폰 공용). v6의 펼친 책 공유 기능을 유지합니다.

## v7 변경점
- 캐릭터: 매끈한 단일 머리 모양, 돌출되는 앞머리/뺨 머리카락 제거, 간결한 눈·표정, 남녀 선택 유지
- 다과룸: 의자 **전부 제거**, 높이가 높은 스탠딩 다과 테이블, 3D 과자와 젤리 및 찻잔 추가
- 다과룸 안에서 `E` 또는 스마트폰의 **상호작용** 버튼을 누르면 차/과자/젤리를 선택할 수 있습니다.
- 과자·젤리를 선택하면 효과음, 반짝임, 다른 참가자에게 전달되는 이모지 효과가 생깁니다.
- 모바일 하단 및 오른쪽의 '앉기' 대신 **상호작용**으로 통일했습니다. 모임방에서는 앉기/일어서기, 다과룸에서는 간식 고르기, 화장실에서는 손 씻기가 작동합니다.
- 기존의 실시간 멀티플레이/채팅/마이크, 방 간 이동, 개인별 펼친 책, 대신 읽기 등은 유지합니다.

## 실행
Node.js 18 이상에서 이 폴더의 `node server.js` 실행 후 `http://localhost:3000` 접속. 같은 방 코드로 접속하면 다른 사용자와 공유됩니다.

## Render 배포
ZIP 압축을 풀어 GitHub 저장소의 루트에 전체 내용을 업로드. Render → **New → Web Service** → GitHub 연결. Language: Node, Build Command: `echo "No dependencies to install"`, Start Command: `node server.js`. 공개 주소는 배포 완료 후 생성됩니다.

## 참고
- 게임 안의 간식은 가상의 상호작용이며 실제 상품 주문이나 결제 기능은 없습니다.
- 글은 서버 메모리에서만 공유되고 영구 저장되지 않습니다. 자신의 초안은 브라우저 로컬 저장소에 저장됩니다.
- 음성 WebRTC는 연결 상황에 따라 제한이 있을 수 있으며 브라우저 마이크 권한이 필요합니다.
