# 아마추어 글쓰기 3D v14.5 — 조용한 걸음과 조명 상호작용

v14.4의 글쓰기·채팅 보존·음악·3D 캐릭터·심리방을 유지하고 다음을 반영했습니다.

- 걸음 효과음 크기: 기존 0.18 → 0.09 (출력 진폭 절반)
- 해먹에서 일어나기: 벽쪽이 아닌 심리방 중앙 방향의 안전한 위치 우선
- 식물 6곳에 ‘물주기’ 근접 상호작용 추가 (초록색 광원 효과)
- 모임방 스탠드 조명에 켜기/끄기 상호작용 추가
  - 3D 광원 계산, 램프 전구, 빛 번짐이 함께 바뀝니다.
  - 같은 모임방에 접속한 참가자에게 조명 상태가 동기화됩니다.
- 상호작용 뒤 물방울/이모지/파티클 비산 효과 제거, 광원 펄스 효과만 유지
- 근접 안내에 식물 물주기와 스탠드 끄기/켜기 안내 포함

**참고:** 서버 메모리의 조명 상태는 서버 재시작 시 켜짐 상태로 초기화됩니다. 식물 물주기는 시각적 반응이며 성장 시뮬레이션은 아닙니다. 모바일 기기 및 WebGL 환경별 확인이 필요합니다.
