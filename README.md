# 아마추어 글쓰기 3D — v14.10

v14.9의 책장 등록 버그 수정, 공유 글, 채팅 보존, 배경음악, 다과·식물·조명 상호작용을 유지하면서 심리 모임방을 업데이트한 버전입니다.

## 이번 변경

- **같은 3D 책장 두 개:** 글쓰기 모임방 왼쪽 벽과 심리 모임방 오른쪽 벽의 책장을 같은 4단 나무 책장으로 통일했습니다. 양쪽 책장은 같은 모임방 코드에 등록된 글을 보여줍니다.
- **8인 원형 모임 + 중앙 테이블:** 여덟 개 철제 의자와 카우치를 유지하고 중앙에 작은 원형 테이블을 배치했습니다.
- **마음 활동 복구:** 원형 테이블의 전체 둘레에서 `E`키 또는 화면의 `상호작용`을 누르면 **내 마음 알아보기 / 내 마음 몰라보기**를 선택할 수 있습니다. 테이블 안쪽 가까이에서는 이 활동이 의자 앉기보다 우선합니다. 의자 바깥쪽에서는 각각 앉기와 일어서기가 작동합니다.
- **이동 및 충돌:** 테이블은 통과할 수 없고 의자 사이 통로로 테이블 주변에 접근할 수 있습니다. 책장도 통과할 수 없도록 이동 충돌을 조정했습니다.

## 시작하기

1. Node.js 18 이상을 설치합니다.
2. 이 폴더에서 `npm start`를 실행하거나 Windows의 `시작_윈도우.bat`, Mac의 `start_mac.command`를 엽니다.
3. 모임방에 입장한 다음 `✧ 여섯 얼굴의 방`으로 이동합니다.
4. 원형 테이블 **가까이** 다가가면 마음 활동 안내가 나타납니다. `E` 또는 모바일의 `상호작용`으로 활동창을 열 수 있습니다.

## 공유 책장

글쓰기 화면에서 `📚 내 글 책장에 꽂기`를 **직접 누른 작품만** 같은 모임방 참가자에게 공개됩니다. 글쓰기 모임방과 심리방의 책장에서 같은 목록을 보고 책처럼 읽을 수 있습니다.

## 데이터 보존 주의

서버는 기본적으로 `data/room-books.json`에 책을 저장합니다. Render 무료 인스턴스의 임시 파일은 재시작 또는 재배포 시 사라질 수 있습니다. 오래 보존하려면 지속성 있는 저장 공간을 연결하고 `BOOKSHELF_DATA_DIR` 환경변수를 설정해야 합니다. 이미 본인의 브라우저에 남아 있는 복사본은 서가의 **다시 공유하기** 기능으로 복원할 수 있습니다.
